Sack BTA mod source - revision 1.0.5+8.0.1

Changes in this revision:
- Removed the right-click hook from ItemStack.useItemRightClick, which was not reached during the user's in-game test.
- Added SackItemUseMixin injecting into Item.onUseItem(ItemStack, World, Player). This is the actual BTA item-use callback identified from the target API; Item.onUseItem is final, so it must be intercepted rather than overridden.
- Logs on item-use entry and before server-side container opening to diagnose whether the callback is reached.
- Keeps the six-slot ContainerSimple chest-style container, NBT content persistence, 3 leather + 1 string shapeless recipe, creative Drops placement, and the existing tweaked texture.

Important multiplayer note: for a container to open and synchronize correctly on a multiplayer server, Sack must be installed on both the client and the server. A client-only install can register the Sack locally but cannot run the server-side container-opening code on a remote server.

Build with GitHub Actions. This revision has not been compiled or tested in-game in the current environment.
