Sack BTA mod source - diagnostic revision 1.0.7+8.0.1

Change in this revision:
- Fixes the diagnostic mixin target that caused the prior startup crash. BTA 8.0.1 is based on Minecraft Beta 1.7.3, whose mouse handling uses Minecraft.clickMouse(int button) for both buttons; button 1 is right-click. The hook now targets clickMouse(I)V and logs only right-clicks.
- Sack ItemStack diagnostics only log when the selected stack is the Sack, reducing noise.
- Bumps the mod version to 1.0.7 so the artifact is easy to identify.

This is still a diagnostic build, not a confirmed fix for opening the screen. It retains the previous ItemStack.useItemRightClick and Item.onUseItem checkpoints so the log can identify which path is actually reached.

Build through GitHub Actions and install only the new sack-1.0.7+8.0.1.jar. Please verify that this new version starts before testing right-click behavior.
